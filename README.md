## 📖 Overview


**CertifyChain** is a production-grade Web3 decentralized application (dApp) designed to combat resume fraud and secure professional credentials. 

It empowers authorized educational institutions and organizations to permanently anchor academic certificates to the **Ethereum blockchain**. By combining mathematically unbreakable cryptographic hashes with decentralized **IPFS** document storage, CertifyChain guarantees that issued certificates are immutable, tamper-proof, and instantly verifiable by anyone in the world.

---

## ✨ Key Features

- **🔒 Immutable Blockchain Anchoring:** Certificate metadata is hashed (Keccak256) and permanently stored on the Ethereum Sepolia testnet.
- **📂 Decentralized Storage (IPFS):** Physical PDF certificates are securely uploaded to the InterPlanetary File System via Pinata, ensuring 100% uptime and permanent availability without centralized servers.
- **🛡️ Role-Based Access Control:** An administrative panel allows the contract owner to whitelist or revoke "Authorized Issuers", preventing unauthorized wallets from minting fake credentials.
- **⚔️ Zero-Gas Duplicate Prevention:** A custom off-chain algorithm scans historic smart contract event logs on-the-fly to block duplicate Certificate IDs before any gas fees are spent.
- **👁️ Hardened PDF Previews:** Custom CSS-isolated `iframe` previews prevent unauthorized downloading while providing a seamless, read-only viewing experience.
- **✅ Instant Public Verification:** Employers can verify a certificate's authenticity instantly by uploading a hash or scanning a dynamic QR code generated by the platform.

## ⚙️ Local Development Setup

### 1. Prerequisites
Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v16+)
- [MetaMask Wallet Extension](https://metamask.io/)

### 2. Installation
Clone the repository and install the required NPM packages.
```bash
git clone https://github.com/your-username/certifychain.git
cd certifychain/Frontend
npm install
```

### 3. Environment Variables
Create a `.env` file in the root of the `Frontend` directory and populate it with your secure credentials:
```env
VITE_PINATA_JWT=your_pinata_jwt_token
VITE_API_SECRET=your_pinata_secret
VITE_PINATA_API_KEY=your_pinata_api_key
VITE_CONTRACT_ADDRESS=your_deployed_contract_address
VITE_SEPOLIA_RPC=your_infura_or_alchemy_rpc_url
```

### 4. Start the Application
Boot up the Vite development server.
```bash
npm run dev
```

## 📝 Smart Contract Architecture

The core of the application relies on `CertificateVerification.sol`, deployed on the Sepolia Testnet. 

**Smart Contract Address:** `0x51C0d20B42ae07dcF7d0053D13c47b48Df9b368C`

### Core Functions:
- `addIssuer(address)`: Allows the Owner to whitelist a new institution.
- `issueCertificate(bytes32 certHash, string name, string course, string ipfsHash)`: Allows an authorized issuer to mint a certificate to the blockchain.
- `verifyCertificate(bytes32 certHash)`: A public read function that returns the certificate data if the hash matches.
- `revokeCertificate(bytes32 certHash)`: Allows an issuer to invalidate a certificate if it was issued in error or fraudulently.
